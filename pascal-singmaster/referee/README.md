## The rule

A frozen version does not move. Improvements go into a **new** version with an entry in
the log; the superseded file is never edited, so a referee holding an older copy can
always see exactly what differs. Editing a frozen file in place is itself a defect.

The point is not ceremony. A text that keeps changing cannot be attacked, because every
objection lands on something that has already moved. V1 was frozen and was holed within
the hour — which is the argument for freezing, not against it.
