## Current result

For shares r_i of an augmented total with q=sum(r_i), exact allocation of the original M and return of the borrowed b require

    T = M/q
    b = M(1-q)/q
    x_i = M r_i/q

Positive borrowing requires 0<q<1. Whole-unit feasibility additionally requires integer T and integer x_i for every recipient. These are separate gates. The seven-camel case passes with M=7, T=8, b=1, and allocations 4, 2, 1.

## Literature and scope

The exact seven-camel puzzle with shares 1/2, 1/4, and 1/8 appears in Ian Stewart's *Scientific American* column reproduced in the [OEIS source scan](https://oeis.org/A002966/a002966_1.pdf). Classical apportionment of indivisible resources is an established neighboring field; the R02 source note records a published formulation and the limits of this initial search. The exact-return identity is elementary conservation algebra. Exhaustive originality review has not been done and no novelty is claimed.

This is mathematically distinct from the finite physical holding capacity in the berth lane. A borrowed arithmetic unit is an exact accounting device; a real holding place is occupied over time and can create backpressure. The analogy does not transfer operational assumptions.
