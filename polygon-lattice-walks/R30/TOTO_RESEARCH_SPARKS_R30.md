## General scaffold theorem on a fixed finite state graph
A state u carries a real symmetric information matrix H(u), with E(u)=lambda_min(H(u)). Fix start s, destination t, E(t)>=E(s)=E0 and a nonempty path family connecting them. Define B=min over paths max over states (E0-E(u)), including the start; for a finite connected graph this minimum is attained. Permit one independent auxiliary PSD matrix Q to be added before departure, retained during a path in the original graph, and removed at the destination. Only discrete state scores are considered; the floor requirement is E>=E0, NOT nondecreasing E at every step. No correlated source, cost, safety, temporal, or activation constraint modeled.
For Q=delta I, E(H+Q)=E(H)+delta exactly. Therefore the minimum sufficient scalar delta is B: choose a minimax path and add B I. Smaller delta cannot work on any path. Addition and final removal satisfy the same original floor. For any PSD Q, Rayleigh quotient at a minimum eigenvector of H gives E(H+Q)<=E(H)+lambda_max(Q)<=E(H)+tr Q. Every path contains a state whose unassisted score is at most E0-B, so tr Q>=B is necessary. This holds even for state-dependent auxiliary PSD matrices whose trace is uniformly bounded; a dynamic activation process is not modeled. In dimension two the minimum trace of a fixed feasible PSD scaffold is between B and 2B. This is a capacity bound, not a financial one.

## R28 single-exchange family
q>=1, k=q+1, e=1/(8*k*q^3), r=k/2, count state (j,l) with j in {0,1}, 0<=l<=q. x=r-(j+l)e, y=(jq-l)/(2q), H=(beta+k)I+[[x,y],[y,-x]], E0=beta+k-r, beta>0. f=x^2+y^2. Start (0,0), optimum (1,q); use original single-swap graph. R28 gives m=ceil(q/2), F*=f(0,m), Delta=F*-r^2 and B=sqrt(F*)-r. The final gain G=k e. Full balanced auxiliary group I (same trace 2 as original groups) is enough for every count state since x<=r, x>0, |y|<=1/2, hence f<=r^2+1/4<(r+1)^2. One additional independently measured balanced group suffices to keep the original E floor during a sequence of ordinary single swaps. This does not imply such a source is available, or that its removal never lowers the immediately preceding score.

## Directional scaffold
Consider Q=diag(0,w), w>=0, which supplies only the second coordinate direction. H+Q-E0 I=[[r+x,y],[y,r-x+w]]. Since r+x>0, the PSD condition is exactly w>=max(0,(f-r^2)/(r+x)). Define that rational threshold W(j,l). The smallest feasible w over all single-swap paths is
w*=Delta/(k-m e).
Proof: 0<w*<1 since Delta>0 by R28, Delta<=1/4 and k-m e>=k-1/8. At any fixed w in [0,w*], the PSD condition is y^2<=(k-a e)(a e+w), a=j+l. Along row j=1 the left side decreases with l and the right side increases (derivative in a e is k-2a e-w>0 for k>=2, a e<=1/8, w<1). Along row j=0 W increases for l>=0 because f(0,l) increases by R28, numerator is nonnegative and denominator decreases. Every path first crosses from (0,l) to (1,l) or (1,l-1). If l>=m, departure requires at least w*. If l<m, arrival has index <=m-1, so its requirement at any w<=w* is at least as restrictive as state (1,m-1). This latter has the same x as (0,m) and |y|>=m/(2q), hence requires >=w*. Thus no w<w* works. The path that first inserts m c sources, then b, then remaining c sources works at w*: first row is safe, (1,m) has |y| no larger than (0,m) and greater a, so determinant inequality remains true, then row 1 stays safe. This proves optimum for this specified direction, not necessarily the exact optimum over arbitrary PSD directions.
Since trace Q=w*, compare to isotropic trace 2B:
w*/B=(sqrt(F*)+r)/(k-m e) ->1 as q grows.
Thus if T_min is minimal fixed PSD auxiliary trace, B<=T_min<=w*, and T_min/B ->1. Directional trace relative to balanced minimal trace tends to 1/2. The equal-capacity requirement is relaxed for these fractional auxiliary matrices, unlike the full I group. Q is PSD rank one, not strictly positive definite; a tiny positive isotropic addition would preserve safety if strictly PD required. The minimum trace tends to zero, but w*/G~q^2/2, so transition support may still be large relative to eventual gain. No general claim that all traps can be escaped by one ordinary group of trace 2.

## Margin
A temporary element need not belong to the best final configuration. Distinguish an extra capacity budget from larger simultaneous moves and distinguish maintaining a baseline floor from stepwise monotonicity. A targeted scaffold nearly attains the universal trace lower bound in this family; the remaining question is when a single direction suffices for multiple distinct weak eigendirections, and how uncertainty or correlated measurements changes the capacity requirement.
