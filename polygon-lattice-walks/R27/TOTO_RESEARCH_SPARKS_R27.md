## Reduction

Maximize E=beta+kR-||sum v_i||, equivalent to minimizing squared imbalance. Distinct source identities may have identical information matrices, but are assumed independently measured. An r-exchange replaces r selected identities by r unselected identities simultaneously, preserving cardinality.

## Strict traps of arbitrary exchange radius
For any integer q>=1 set k=q+1, R=1 and epsilon=1/(8*k*q^3). Choose a pool of 2k distinct source identities: k copies of a=(1/2,0), one b=(1/2-epsilon,1/2), and q copies of c=(1/2-epsilon,-1/(2q)). All vectors lie strictly inside the unit disk, so all groups are positive definite and equal trace. Start with all a sources, sum (k/2,0). A replacement of m=j+l sources uses j in {0,1} b sources and l in {0,...,q} c sources. Its sum is (k/2-m*epsilon,(jq-l)/(2q)).
For 1<=m<=q the second coordinate is nonzero with absolute value >=1/(2q): jq=l is possible only for j=l=0 or j=1,l=q. The squared norm difference from the initial set equals -k*m*epsilon+m^2*epsilon^2+(jq-l)^2/(4q^2), strictly positive because k*m*epsilon<=1/(8q^2). Thus EVERY nonempty exchange of at most q sources strictly worsens E. Replacing all k sources makes the second coordinate zero, and the first strictly smaller and positive. Since every other selection worsens the initial set, this full replacement is the unique optimal selection by identities. This is an arbitrary exchange-radius barrier under equal trace, even with strictly PD groups. It is not an unbounded approximation-loss result: the full E improvement is only k*epsilon=1/(8q^3), shrinking as q grows. A monotone method restricted to at most q simultaneous exchanges cannot escape; methods with temporary worsening, restarts or larger moves are not ruled out.

## General quality bound for one-exchange local optima
Let a locally optimal k-set have sum s, r=||s||, and let an optimal set have sum t, d=||t||<=r. All vectors have norms <=R. If r=0 the local set is already optimal. Otherwise let u=s/r. Write a_i for the removed vectors and b_i for the inserted vectors of any bijection between the two difference sets; common vectors are retained. One-exchange local optimality gives 2s dot (a_i-b_i)<=||a_i-b_i||^2. Define nonnegative deficits A_i=R-u dot a_i and B_i=R-u dot b_i. Since ||a_i-Ru||^2<=2R A_i and similarly for b_i, the squared triangle inequality gives ||a_i-b_i||^2<=4R(A_i+B_i). Thus (r-2R)sum B_i <=(r+2R)sum A_i. For r>2R, put A=sum A_i and B=sum B_i; A<=kR-r=G, the local E gain above baseline. The optimal gain G*=kR-d<=kR-u dot t=G+B-A<=((r+2R)/(r-2R))*G. Consequently G/G* >= (r-2R)/(r+2R) when G*>0 and r>2R. Also G/G* >=1-r/(kR) for all r, because G*<=kR. For k>=3 set r0=R*(sqrt(1+4k)-1), which lies between 2R and kR. The two lower bounds agree at r0; for r<=r0 use the decreasing linear bound and for r>=r0 the increasing rational bound. This gives
G >= c_k G*, c_k=1-(sqrt(1+4k)-1)/k.
If G*=0 the inequality holds trivially. The same bound holds for total E with positive isotropic baseline. c_k tends to 1 as k grows. No sharpness claim. For k=2, if a local pair is not optimal then any optimal pair sharing one identity would contradict local optimality, so an optimal pair is disjoint. The local norm r is no larger than any cross-pair norm. Averaging the four squared cross norms gives r^2<=2R^2+s dot t/2<=2R^2+R*d. Rationalizing as in R26 proves G>=G*/4. This separate two-choice bound is not claimed sharp for local optima.
The general bound is about a true one-exchange local optimum, not a finite-time guarantee for a particular implementation. No transfer to unequal trace, unequal cost, higher matrix dimension or correlated readings.
